# Vektet 100: pullups og dips

Treningsprogram og app for å nå **+100 kg vektede pullups** og **+100 kg vektede dips**.

Utgangspunkt: pullups +45 kg (topp tidligere +60), dips +40 kg × 2 (topp tidligere +62,5).

Appen er én HTML-fil uten byggesteg. Åpne `trening/index.html` i nettleseren, eller via GitHub Pages.
Data (logg, innstillinger) lagres i nettleseren. Bruk Eksporter i Innstillinger som backup.

## Programmet

3 økter i uka (f.eks. man/ons/fre). Begge løftene hver økt.
Alle prosenter er av **total last** (kroppsvekt + belte) i forhold til **treningsmaks (TM) = 95 % av estimert 1RM**.

### Fase 1: Gjenoppbygging (uke 1–8)
Målet er å komme tilbake til gammel topp (muskelminne går fort).

| Dag | Innhold |
|---|---|
| A · Tung | 4×5 @ 85 → 92,5 % TM |
| B · Volum | 4×8 @ 75 → 82,5 % TM |
| C · Fart | 6×3 @ 80 → 87,5 % TM, eksplosivt |

Uke 4 er deload. Uke 8 avsluttes med et AMRAP-sett som rekalibrerer TM.

### Fase 2: Styrkeblokker (uke 9 og videre)
4-ukers blokker basert på 5/3/1:

| Uke | Dag A · Tung | Dag B · Volum | Dag C · Singler |
|---|---|---|---|
| 1 | 75/82,5/90 % × 5/5/5+ | 5×5 @ 77,5 % | 6×1 EMOM @ 87,5 % |
| 2 | 80/87,5/95 % × 3/3/3+ | 5×5 @ 80 % | 6×1 EMOM @ 90 % |
| 3 | 82,5/92,5/100 % × 5/3/1+ | 5×5 @ 82,5 % | 6×1 EMOM @ 92,5 % |
| 4 | Deload 65/70/75 % × 5 | 3×5 @ 70 % | 3×3 @ 70 % |

Hver 3. blokk er uke 4 en **testuke** (ramp opp til ny 1RM).
Etter hver blokk settes ny TM til 95 % av beste estimerte 1RM du logget, maks ±5 kg per blokk. Uten logg: +2,5 kg.

Tilbehør roterer: rader, curls, skulderpress, triceps, face pulls, scapula pulls, core.

## Realistisk tidslinje
Estimert ~2–2,5 år. Rask fremgang tilbake til +60 kg, deretter ~2,5 kg per måned som gradvis avtar mot 100 kg.
Prognosen i appen oppdateres fra det du logger.
