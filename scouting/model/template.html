The game model

What Horneland's Brann asks for

A 4-3-3 with the most aggressive press in the league (PPDA 6.57 in 2024; 421 counter-press recoveries, a league high). In possession the right-back goes high and the left-back steps inside beside the 6, which builds a 2-2 base behind five attackers. In 2026 Brann were 2nd for box touches but 13th for big chances missed and 9th for xG against. Each role's weights below come from those demands.

How the scores work

Method and limits

Scoring

  • Pool: 11,153 player-seasons with 900+ league minutes, pulled from Sofascore on 11 Oct 2026. Calendar-year leagues use 2026; Aug–May leagues use the completed 2025/26 season. Goalkeepers are excluded.
  • Role: taken from the player's primary Sofascore position. DC = centre-back; DL/DR = full-back; DM/MC = central midfield; LW/RW/ML/MR = winger; ST = striker.
  • Style fit (0–100): each metric becomes a percentile against every player in the same role across all 46 leagues. The fit is the weighted average using the role weights above. "Dribbled past" and errors count in reverse.
  • Coverage: some leagues don't publish tackles, interceptions or xA. Missing weight is dropped and the score is pulled toward 50 in proportion, so a player with half the data can't post an extreme score.
  • Brann score = style fit × league factor, with the Eliteserien at 1.00. Factors are judgement calls based on league strength; the full table is below.

Read it with care

  • This is event data, with no tracking. Pace, distance run and repeat sprints, all central to Horneland's press, are not measured. Every centre-back needs a video and pace check.
  • Stats reflect each player's team. A ball-winner in a deep block and one in a high press can post similar tackle counts for different reasons.
  • Players who moved this summer are hidden by default. Untick the box to see them. Many have joined bigger clubs and are no longer realistic.
  • Market values are Sofascore estimates and contract dates are Sofascore's. Check both against Transfermarkt and agent information before any approach.
  • The model ranks style match only. It does not judge character, injury history, wages or whether the player would come.
