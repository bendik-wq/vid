# Offer architecture — The Owners Academy

Built on Hormozi's Grand Slam Offer method ($100M Offers): value equation →
problem/solution inventory → delivery vehicles → stack → price → guarantee →
scarcity → naming.

| File | What it is |
|---|---|
| `value-equation.md` | The four levers, scored before and after. The reasoning every offer below inherits. |
| `offer-ladder.md` | The four rungs — free training, kit, core program, deal desk — with price, guarantee, scarcity and naming for each. |
| `problem-solution-map.md` | Every obstacle between a prospect and their first acquisition, converted to a solution, then to a deliverable. This is where the bonuses come from. |
| `objection-map.md` | Which offer element kills which objection. Use this to audit any page or script. |
| `../webinar/OFFER.md` | The free training offer as it appears on the live opt-in page. |

## Assumptions

These are written as recommendations, not as your existing business. Confirm
before publishing any of it:

- **Prices** are anchored to the value of a single acquisition, not to what
  competitors charge. If your current price is materially different, the stack
  values need rebuilding, not just the headline number.
- **Capacity numbers** (cohort of 25, eight deal desk seats) are the scarcity
  mechanism and must be true. Fake caps are the fastest way to lose a market
  this small and this well-networked.
- **Success fees** on transactions may require a licensed intermediary
  depending on jurisdiction (in the US, the M&A broker exemption is narrow;
  in the UK, FCA perimeter questions apply to some structures). Get the deal
  desk fee structure checked by counsel before it goes on a page.
- **Guarantee liabilities** are real cash. Each one below has a qualifying
  condition and a cap; keep them.
