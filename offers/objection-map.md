# Objection → offer element

Audit tool. Every objection a prospect can raise should have an element of the
offer pointed at it. Where a row has no element, the objection gets handled by
copy alone — which is where offers leak.

| Objection | ICP it comes from most | Element that kills it | Where it appears |
|---|---|---|---|
| "I have no capital" | Corporate Prisoner | Capital Stack Playbook + the entire no-money-down mechanism | Headline, agenda #1 |
| "Banks won't lend to me" | Corporate Prisoner, One-Business Ceiling | Bankability Scorecard + Lender Desk introductions | Agenda #3, stack #3 and #7 |
| "Nobody will sell to me" | All | Board Credibility Packet + off-market outreach | Agenda #2, stack #5 |
| "There are no good deals left" | HNW Deployer | Deal Flow Engine — off-market, unbrokered | Agenda #4, stack #2 |
| "I'll overpay" | HNW Deployer | Normalised EBITDA Workbook + Deal Review | Stack #3, deal clinic |
| "I can't run it, I have a job" | Corporate Prisoner | Operator Hiring Kit + first-100-days plan | Stack #9 |
| "I'll lose everything if it fails" | All | Downside Structuring — no-PG structures, earn-out weighting | Stack #10 |
| "I don't have time" | Trapped Owner | Five-hour weekly sprint, stated up front | Milestone timeline |
| "I've bought courses before and did nothing" | All | Conditional guarantee with participation milestones — the conditions *are* the accountability | Guarantee |
| "What if it doesn't work for me?" | All | Deal or we work free, plus 30-day unconditional | Guarantee |
| "It's too expensive" | Corporate Prisoner | Payment plan + cost-of-inaction framing against one year of not owning | Close |
| "I can figure this out myself" | One-Business Ceiling | Lender relationships and counsel-reviewed paper — the two things that can't be self-taught | Stack #4, #7 |
| "Why should I trust you?" | All | Named advisors, checkable lender relationships, member deals | Proof section |
| "I'll do it later" | All | Cohort of 25, four intakes a year, price rises with proof | Scarcity |

## Two rows that need work

1. **"I've bought courses before and did nothing."** This is the real objection
   in the education market and most offers answer it with enthusiasm. The
   conditional guarantee answers it structurally — but only if the milestones
   are visible *before* purchase. Put the four qualifying conditions on the
   sales page as a feature, not in the terms as a caveat.

2. **"There are no good deals left."** Strongest objection from the
   sophisticated buyer, and the only convincing answer is evidence: a live count
   of owner conversations the cohort is having this month. If you can publish
   that number and keep it current, it does more than any testimonial.
